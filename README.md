# HYROX Trainer

Eigenständige Progressive Web App für HYROX Mixed Doubles, getrennt von FORM. Fitness.

## Start & Installation

Nach Aktivierung unter GitHub → Settings → Pages → Deploy from a branch → main → /(root):

https://bigbro42.github.io/Hyrox/

iPhone: Safari → Teilen → Zum Home-Bildschirm.
Android: Chrome → App installieren / Zum Startbildschirm.

## Funktionen

- 1 Physio-Einheit, 2 Kraft-/HYROX-Einheiten, Fußball nach Knie-Freigabe
- 15 Physio-Übungen und editierbare Trainingsvorlagen
- 16-Wochen-Phasen, Sätze/Gewichte/RPE/Knie-Schmerztracking
- Gamification: XP, Level und Meilensteine, ohne Strafen für Pausen
- Lokale Datenhaltung, JSON-Import/-Export und CSV-Export
- PWA-Offline-Cache nach dem ersten Aufruf

## Wichtige Hinweise

Die App ist kein Medizinprodukt. Bei vorderen Knieschmerzen von 5/10 vor Lauf- und Sprungprogression sportphysiotherapeutisch abklären lassen. Daten bleiben im Browser und gehen möglicherweise bei Datenlöschung oder Gerätewechsel verloren. Backups exportieren.
